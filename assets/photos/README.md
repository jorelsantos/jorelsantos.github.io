# assets/photos

Curated photography for the portfolio's "Beyond work" gallery. Drop full-quality, uncropped exports here.

## Export specs
- **Long edge:** ~2000–2560px (retina-sharp at display size)
- **Format:** WebP quality ~82 preferred; JPEG ~85 is fine
- **Do not pre-crop** — export the full frame; the gallery respects native aspect ratio
- **File size:** ~200–600KB each after compression

The gallery renders these large and uncropped, in the order they're referenced in `index.html`.
