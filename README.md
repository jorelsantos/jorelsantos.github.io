# jorelsantos.github.io

Personal portfolio site. Plain HTML + Tailwind (via CDN) — no build step, deploys
straight to GitHub Pages from `main`.

## Editing

Just edit `index.html` and push to `main`. Pages redeploys automatically in
~1 minute. Live at https://jorelsantos.github.io

## Demo assets

Screenshots and short demo clips for each project live in `assets/demos/<slug>/`.
The markup is already wired (commented out) in `index.html`: drop an optimized
file into the project's `web/` folder, uncomment its `DEMO MEDIA` block, and push.
See `assets/demos/README.md` for export specs and the full workflow.
